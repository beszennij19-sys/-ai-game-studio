# AI Game Studio 3.8 — AI World Generator

3.8 extends the pipeline from characters to complete game worlds.

## Pipeline
Blueprint -> World Plan -> Locations -> Terrain/Architecture/Props -> Roads/Paths -> Points of Interest -> Spawn Points -> Scene Manifest -> Unity

## Project isolation
World data and jobs are scoped to:
`Generated/<ProjectID>/World/<WorldID>/`

## Backend
- `POST /api/projects/:id/worlds/:worldId/jobs`
- `GET /api/world-jobs/:jobId`

The provider adapter is separated from orchestration so real environment/3D providers can be connected without exposing API keys in the client.

## Unity
`AI Game Studio -> 3.8 -> Prepare World Pipeline`

The generated SceneManifest describes what the Unity scene should contain. Unity Editor is still required to import generated assets, create terrain/prefabs, configure navigation and save the final scene.

## Important
3.8 provides the executable planning/orchestration/import-preparation layer. It does not falsely claim that an entire photorealistic open world is generated by this ZIP alone. Actual terrain/architecture/vegetation/model generation requires connected asset providers.
