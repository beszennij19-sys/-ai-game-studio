# AI Game Studio 5.6 — AI Generated 3D Preview

5.6 unifies Blueprint-derived world entities and mechanics into one interactive browser preview. It is a lightweight preview runtime, not a replacement for Unity/Unreal and not a claim of final photorealistic asset generation.

The preview reads `aigame_blueprint_5_6` from localStorage when embedded in the Web Studio. It adapts camera profile, enemies, resources, NPC/quest markers and mechanics from the project's Blueprint.
